# 🧠 Margem Humana

## 📌 Descrição do Projeto

O projeto **Margem Humana — Quem pode discordar da IA no primeiro emprego?** consiste no desenvolvimento de um site educativo e interativo que aborda os desafios enfrentados por jovens profissionais diante da utilização da inteligência artificial no ambiente de trabalho.

O objetivo principal é promover uma reflexão sobre autonomia, pensamento crítico, empatia e responsabilidade no uso de ferramentas de IA, demonstrando a importância da participação humana nas decisões profissionais.

Desenvolvido como parte da disciplina de **Desenvolvimento Front-End Para Web (2026.2)**, o projeto apresenta um simulador interativo com quatro situações fictícias relacionadas ao atendimento ao cliente, permitindo que o usuário tome decisões e receba feedbacks sobre suas escolhas.

O sistema apresenta situações envolvendo:

- **Decisões automatizadas:** análise crítica de respostas sugeridas pela inteligência artificial.
- **Empatia no atendimento:** importância de compreender as necessidades dos clientes.
- **Pressão por produtividade:** impactos das metas de velocidade na qualidade das decisões.
- **Aprendizado profissional:** utilização da IA como ferramenta de apoio, sem substituir o raciocínio humano.

Além disso, a plataforma apresenta gráficos interativos baseados em pesquisas sobre inteligência artificial, produtividade e expectativas profissionais, proporcionando uma experiência educativa e informativa.

## 💻 Tecnologias Utilizadas

- **Linguagens:** HTML5, CSS3 e JavaScript.
- **Bibliotecas:** Bootstrap 5 e Chart.js.
- **Estilização:** CSS personalizado, Flexbox, Grid e Media Queries.
- **Ferramentas:** Visual Studio Code (VSCode), GitHub e Node.js.
- **Modelo de IA:** ChatGPT, utilizado como ferramenta de apoio ao desenvolvimento.
- **Hospedagem:** GitHub Pages.

## 📊 Resultados e Aprendizados

O projeto resultou no desenvolvimento de uma aplicação web educativa, com interface moderna, navegação interativa e funcionalidades que estimulam a reflexão sobre o uso responsável da inteligência artificial.

Durante o desenvolvimento, foram trabalhados e aprimorados os seguintes conhecimentos:

- **Estruturação HTML:** organização de páginas e conteúdos utilizando elementos semânticos do HTML5.
- **Estilização e Responsividade:** criação de uma interface adaptável a diferentes dispositivos, utilizando CSS3 e Bootstrap.
- **Interatividade com JavaScript:** implementação de funcionalidades dinâmicas para interação dos usuários com a aplicação.
- **Simulador de Decisões:** desenvolvimento de quatro cenários interativos, com alternativas, feedbacks e pontuação educativa de 0 a 8 pontos.
- **Visualização de Dados:** utilização da biblioteca Chart.js para apresentar gráficos interativos com indicadores baseados em pesquisas.
- **Manipulação do DOM:** atualização dinâmica de elementos, resultados e informações exibidas na página.
- **Personalização da Interface:** implementação de alternância entre tema claro e escuro, com armazenamento da preferência do usuário.
- **Exportação de Resultados:** implementação de funcionalidade que permite gerar e baixar um protocolo de revisão em formato `.txt`.
- **Acessibilidade:** aplicação de recursos para facilitar a navegação por teclado e a compreensão das informações.
- **Publicação Web:** utilização do GitHub e GitHub Pages para versionamento e disponibilização do projeto.

O desenvolvimento contribuiu para o aprimoramento de conhecimentos técnicos em Front-End, além de proporcionar uma reflexão sobre os limites da automação, a importância do pensamento crítico e a responsabilidade humana nas decisões auxiliadas por inteligência artificial.

## 🤖 Declaração de Uso Ético da IA

Este projeto utilizou inteligência artificial, por meio do **ChatGPT**, como ferramenta de suporte tecnológico durante o processo de desenvolvimento.

A ferramenta auxiliou na estruturação do HTML, estilização com CSS, implementação de funcionalidades em JavaScript, criação do simulador, integração dos gráficos e identificação de possíveis melhorias na aplicação.

O desenvolvimento contou com assistência de IA na geração e revisão de código. O projeto também possui registros de avaliação de funcionalidades pelos integrantes, além de documentação de auditoria que identifica implementações e ajustes realizados com auxílio da ferramenta.

O uso da inteligência artificial foi documentado de forma transparente, distinguindo as contribuições automatizadas das revisões relatadas pelos desenvolvedores e mantendo a responsabilidade pela apresentação, avaliação crítica e integridade do trabalho final.
