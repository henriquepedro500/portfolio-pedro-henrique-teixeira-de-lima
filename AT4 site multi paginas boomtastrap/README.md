# 🎮 Portal Games

## 📌 Descrição do Projeto

O projeto **Portal Games** consiste no desenvolvimento de uma plataforma web voltada ao universo dos jogos digitais, com o objetivo de proporcionar aos usuários uma experiência de navegação prática, organizada e visualmente atrativa.

O objetivo principal é reunir conteúdos relacionados a jogos em um ambiente digital acessível, utilizando uma interface intuitiva que facilite a interação e a navegação dos usuários.

Desenvolvido como parte da disciplina de **Desenvolvimento Front-End Para Web (2026.2)**, o projeto utiliza tecnologias de desenvolvimento web para estruturar as páginas, personalizar elementos visuais e implementar funcionalidades interativas.

A aplicação busca unir entretenimento e tecnologia, demonstrando a aplicação prática dos conhecimentos adquiridos durante a disciplina.

## 💻 Tecnologias Utilizadas

- **Linguagens:** HTML5, CSS3 e JavaScript.
- **Estilização:** CSS para personalização de layouts, cores, fontes e elementos visuais.
- **Ferramentas:** Visual Studio Code (VSCode) e GitHub.
- **Modelo de IA:** Gemini, como ferramenta de apoio ao desenvolvimento.
- **Hospedagem:** GitHub Pages.

## 📊 Resultados e Aprendizados

O projeto teve como resultado o desenvolvimento de um portal web relacionado ao universo dos games, permitindo colocar em prática os conhecimentos de desenvolvimento Front-End.

Durante o desenvolvimento, foram trabalhados os seguintes conhecimentos:

- **Estruturação HTML:** organização das páginas e dos conteúdos utilizando elementos HTML5.
- **Estilização CSS:** criação de layouts, personalização de cores, fontes, botões e outros componentes visuais.
- **Interatividade com JavaScript:** utilização de lógica de programação para implementar comportamentos dinâmicos na interface.
- **Organização de Conteúdo:** desenvolvimento de uma estrutura visual para facilitar a apresentação e o acesso aos conteúdos.
- **Experiência do Usuário:** aplicação de princípios de navegação e usabilidade para tornar a plataforma mais intuitiva.
- **Publicação Web:** aprendizado sobre versionamento de código, utilização do GitHub e hospedagem de sites pelo GitHub Pages.

O desenvolvimento do Portal Games contribuiu para aprimorar habilidades em HTML, CSS e JavaScript, além de proporcionar experiência prática na criação e publicação de projetos web.

## 🤖 Declaração de Uso Ético da IA

Este projeto utilizou inteligência artificial, por meio do **Gemini**, como ferramenta auxiliar de suporte tecnológico durante o processo de desenvolvimento.

A ferramenta foi utilizada como apoio na estruturação inicial do HTML, estilização com CSS, organização de funções em JavaScript e identificação de possíveis melhorias no código.

Todo o código desenvolvido com auxílio da inteligência artificial foi revisado, testado e compreendido pelo desenvolvedor, garantindo sua responsabilidade pela autoria final, integridade e funcionamento da aplicação.
