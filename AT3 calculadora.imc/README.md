# 🧮 Calculadora de IMC

## 📌 Descrição do Projeto

Este projeto consiste no desenvolvimento de uma **Calculadora de IMC (Índice de Massa Corporal)**, uma aplicação web interativa que permite aos usuários calcular seu índice de massa corporal a partir de informações como peso e altura.

O objetivo principal é oferecer uma ferramenta simples, prática e intuitiva para realizar o cálculo do IMC e apresentar uma classificação de acordo com o resultado obtido.

Desenvolvido como parte da disciplina de **Desenvolvimento Front-End Para Web (2026.2)**, o sistema utiliza JavaScript para realizar cálculos matemáticos, validar os campos preenchidos e apresentar os resultados dinamicamente na página, sem necessidade de recarregamento.

A aplicação apresenta seis classificações: baixo peso, peso normal, sobrepeso, obesidade grau I, obesidade grau II e obesidade grau III.

## 💻 Tecnologias Utilizadas

- **Linguagens:** HTML5, CSS3 e JavaScript.
- **Estilização:** CSS personalizado.
- **Ferramentas:** Visual Studio Code (VSCode).
- **Modelo de IA:** Gemini, como ferramenta de apoio ao desenvolvimento.

## 📊 Resultados e Aprendizados

O projeto resultou no desenvolvimento de uma calculadora funcional, capaz de processar as informações fornecidas pelo usuário e apresentar o IMC calculado com sua respectiva classificação.

Durante o desenvolvimento, foram adquiridos e aprimorados conhecimentos importantes:

- **Manipulação do DOM:** aprendi a utilizar JavaScript para capturar informações dos campos HTML e atualizar o conteúdo da página dinamicamente.
- **Lógica de Programação:** implementei operações matemáticas e estruturas condicionais para calcular e classificar o IMC.
- **Validação de Dados:** utilizei verificações para impedir que o cálculo seja realizado quando os campos de peso ou altura não estão preenchidos ou possuem valor zero.
- **Estilização com CSS:** desenvolvi uma interface simples, organizada e de fácil utilização, utilizando cores e efeitos visuais nos botões.
- **Interatividade:** implementei uma função JavaScript acionada pelo botão de cálculo, permitindo apresentar resultados imediatos.
- **Formatação de Resultados:** utilizei métodos do JavaScript para exibir o IMC com duas casas decimais.

O desenvolvimento contribuiu para o aprimoramento das habilidades em HTML, CSS e JavaScript, especialmente na integração entre interface, entrada de dados e lógica de programação.

## 🤖 Declaração de Uso Ético da IA
